# Palindrome Checker in Python
This is a simple Python program that checks whether a given word or text is a palindrome.

## What is a Palindrome?
A palindrome is a word that reads the same forwards and backwards.

### Examples
* madam
* level
* radar
# How to Run
python palindrome.py

## Sample Output
Enter the text/word : madam

madam is a palindrome
